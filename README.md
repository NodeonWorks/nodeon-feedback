## What is Nodeon?

Nodeon is a modern order management platform built for B2B businesses. It helps teams manage purchase orders, sales orders, shipments, and inventory — all in one place.

## Before you open an issue

- **Search first** — your issue may already be reported. Check [open](https://github.com/NodeonWorks/nodeon-feedback/issues) and [closed](https://github.com/NodeonWorks/nodeon-feedback/issues?q=is%3Aclosed) issues before submitting.
- **One issue per report** — don't bundle multiple bugs or requests into a single issue.
- **Be specific** — the more detail you provide, the faster we can help.

## Security

Please **do not** open public issues for security vulnerabilities. Send a report to [security@nodeon.it](mailto:security@nodeon.it) instead. We aim to respond within 48 hours.

## Response times

We review all feedback regularly. While we can't guarantee a timeline for every request, we read everything and use your input to prioritize our roadmap.
